# Qorvo reference: extracted design tokens

- Body font: Geist, system-ui fallback; 16/24 px.
- Display font: Archivo, system-ui fallback.
- Editorial accent: Instrument Serif, Georgia fallback.
- Mono labels: Geist Mono, Consolas fallback.
- Body foreground: `rgb(245, 245, 247)`.
- Accent purple: `rgb(124, 92, 255)` / `#7c5cff`.
- Secondary accent: `rgb(34, 211, 168)` / `#22d3a8`.
- Base background: near-black `#08080b` with violet radial gradients.
- Desktop H1: 78 px, 77.22 px line-height, weight 590.
- Desktop H2: 54 px, 56.16 px line-height, weight 560.
- Mobile H1: 42 px, 41.58 px line-height.
- Section vertical padding: commonly 108 px desktop; 64–80 px mobile adaptation.
